# mapacinc.github.io
MAPAC.org

## Take Action pages

- `take-action.html` is the action center; it reads `campaigns.json` to list campaigns.
- `action-van-hollen-leader.html` is the linked Van Hollen campaign page.
- `action.html` creates shareable campaigns, and `contact-officials.html` contacts officials directly.

The action center maps campaign IDs with dedicated pages in its `PAGES` object. Campaigns without a dedicated page use the share link stored in `campaigns.json`.
